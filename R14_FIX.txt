StemLab r14 installer build fix

Fixed a PowerShell parameter-splatting bug in build_installer_windows.ps1.
The r13 script passed -NoZip through an array, so PowerShell bound the literal
string "-NoZip" to build_portable_windows.ps1's first positional parameter
(PythonVersion). That generated a nonexistent python.org URL and caused the 404.

r14 uses hashtable splatting with named parameters instead.

Run from the extracted root:
  .\build_installer_windows.ps1

If FFmpeg is not on PATH:
  .\build_installer_windows.ps1 -FfmpegPath "C:\path\to\ffmpeg.exe"
